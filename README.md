# Just Timer

Простой, удобный и настраиваемый плавающий таймер для Windows с чистой модульной архитектурой.

## Возможности

- **Минималистичный виджет**: окно без системных рамок, свободно перемещается зажатием ЛКМ.
- **Точный ход времени**: математика на базе системного монотонного таймера (`time.monotonic()`), гарантирующая нулевую погрешность.
- **Разделение клика и перетаскивания**: перетаскивание окна не запускает и не сбивает таймер; короткий клик ставит на паузу или возобновляет отсчет.
- **Управление временем**:
  - Быстрые пресеты в контекстном меню: 1, 3, 5, 10, 15, 20, 25 (Pomodoro), 30, 45, 60 минут.
  - Ввод любого времени вручную (поддерживает `15`, `10:30`, `1h 30m`, `45s`).
  - Быстрая подкрутка колесиком мыши (+ / - 1 мин) на паузе.
- **Режим кругов и интервалов (раунды)**:
  - 5 кругов по 30 сек, 3 круга по 1 мин, Табата (8 кругов 20с/10с), Помодоро (4 круга 25м/5м).
  - Настройка любого количества кругов, времени работы и времени отдыха.
  - Бесконечный цикл (автоповтор).
  - Звуковой сигнал при завершении каждого круга и финальный сигнал.
- **Растягивание окна и авто-шрифт**:
  - Уголок `◢` и края окна позволяют свободно растягивать размер, цифры масштабируются автоматически.
- **Темы и персонализация**:
  - 7 встроенных тем: *Тёмная*, *Светлая*, *Матрица / Неон*, *Киберпанк*, *Янтарь*, *Изумруд*, *Глубокий синий*.
  - Выбор любого цвета цифр, фона и индикации завершения через системную палитру цветов.
  - Регулировка прозрачности: 100%, 90%, 80%, 70%, 60%.
- **Оповещения**:
  - Мягкое визуальное мигание цифр при 00:00:00.
  - Звуковой сигнал Windows (можно отключить в меню).
- **Автосохранение**:
  - Позиция окна, цвета, время, флаг "поверх всех окон" и прозрачность автоматически сохраняются в `config.json`.

## Управление и горячие клавиши

| Действие | Управление |
|---|---|
| **Старт / Пауза** | Клик **ЛКМ** или клавиша `Space` |
| **Перетаскивание** | Зажать **ЛКМ** и переместить в любую точку экрана |
| **Меню настроек** | Клик **ПКМ** |
| **Сброс (Reset)** | Нажатие **колесика мыши (СКМ)** или клавиша `R` |
| **Подстройка минут** | Вращение **колесика мыши** |
| **Ввести своё время** | Двойной клик **ЛКМ** или пункт меню |
| **Поверх всех окон** | Клавиша `T` или чекбокс в меню |
| **Выход** | `Esc` или `Ctrl + Q` |

## Запуск и разработка

### Запуск приложения
```powershell
py run.py
# или
py -m timer_app
```

### Запуск тестов
```powershell
py -m unittest discover -s tests -v
```

### Сборка исполняемого файла (.exe)
```powershell
.\scripts\build_exe.bat
# или
py -m PyInstaller --onefile --noconsole --name "Just Timer" --distpath "./dist" --workpath "./build" --paths "./src" run.py
```
Готовый `.exe` будет создан в каталоге `dist/Just Timer.exe`.
