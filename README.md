# Just Timer

Простой, удобный и настраиваемый плавающий таймер для Windows и Linux с чистой модульной архитектурой.

## Возможности

- **Минималистичный виджет**: окно без системных рамок с отображением на панели задач, свободно перемещается зажатием ЛКМ.
- **Точный ход времени**: математика на базе системного монотонного таймера (`time.monotonic()`).
- **Разделение клика, перетаскивания и двойного клика**: перетаскивание окна и двойной клик не сбивают состояние таймера; короткий клик ставит на паузу или возобновляет отсчет.
- **Управление временем**:
  - Быстрые пресеты в контекстном меню: 1, 3, 5, 10, 15, 20, 25 (Pomodoro), 30, 45, 60 минут.
  - Ввод любого времени вручную (поддерживает `15`, `10:30`, `1h 30m`, `45s`).
  - Подкрутка колесиком мыши на паузе (+ / - 1 мин, либо + / - 10 сек при длительности до 1 минуты).
- **Режим кругов и интервалов (раунды)**:
  - Готовые пресеты (5 кругов по 30 сек, Табата, Помодоро) и настройка своих серий с отдыхом.
  - Бесконечный цикл (автоповтор).
  - Независимая настройка звука окончания круга и звука окончания всего таймера.
- **Растягивание окна за все края и авто-шрифт**:
  - Изменение размера за любые края и углы; цифры масштабируются в пикселях без обрезания табло и статусной строки.
- **Темы и HUD-режим**:
  - 7 встроенных тем и выбор пользовательских цветов.
  - Прозрачный фон (HUD) с контрастной обводкой цифр для читаемости поверх светлых и тёмных окон.
- **Автосохранение**:
  - Позиция окна, размеры, цвета, звуки, круги и флаг "поверх всех окон" автоматически сохраняются в `config.json`.

## Управление и горячие клавиши

Горячие клавиши внутри окна работают независимо от текущей раскладки клавиатуры (EN / RU):

| Действие | Управление |
|---|---|
| **Старт / Пауза** | Клик **ЛКМ**, `Space`, глобально `Ctrl + Alt + Space` (Windows) |
| **Перетаскивание** | Зажать **ЛКМ** и переместить в любую точку экрана |
| **Изменение размера** | Потянуть за любой край или угол окна |
| **Меню настроек** | Клик **ПКМ** |
| **Сброс (Reset)** | Нажатие **колесика мыши (СКМ)**, клавиша `R` / `К`, глобально `Ctrl + Alt + R` (Windows) |
| **Подстройка времени** | Вращение **колесика мыши** |
| **Ввести своё время** | Двойной клик **ЛКМ** или пункт меню |
| **Поверх всех окон** | Клавиша `T` / `Е` или чекбокс в меню |
| **Выход** | `Esc` или `Ctrl + Q` / `Ctrl + Й` |

## Запуск и сборка

### Запуск из исходников
```powershell
py run.py
# или на Linux:
python3 run.py
```

### Запуск тестов
```powershell
py -m unittest discover -s tests -v
```

### Сборка для Windows (.exe)
```powershell
.\scripts\build_exe.bat
```
Готовый `.exe` будет создан в каталоге `dist/Just Timer.exe`.

### Сборка для Linux
Требуются Python 3, пакет `python3-tk`, `pyinstaller`, а для воспроизведения звука один из системных плееров (`paplay`, `pw-play`, `aplay` или `ffplay`):
```bash
chmod +x scripts/build_linux.sh
./scripts/build_linux.sh
```
Готовый бинарный файл будет создан по пути `dist/Just-Timer-Linux`.
