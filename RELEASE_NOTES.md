# Just Timer v1.1.0

Релиз Just Timer v1.1.0 с исправлением отображения на прозрачном фоне, улучшенным масштабированием, поддержкой всех раскладок клавиатуры, отдельным звуком кругов и поддержкой сборки для Linux.

---

### Новое и исправления:
- **Чёткий шрифт в прозрачном режиме (HUD)**: табло переведено на `Canvas` с контрастной обводкой, благодаря чему светлые и тёмные цифры чётко читаются на любом фоне без цветного ореола сглаживания ClearType.
- **Минималистичный режим без строки статуса**: добавлена возможность скрыть нижнюю строку состояния («Таймер запущен», подсказки) через контекстное меню или клавишу `S` (`Ы`), оставив на экране только цифры таймера.
- **Корректное масштабирование без обрезания**: размер шрифта рассчитывается в пикселях с точным замером ширины и высоты, нижняя строка статуса больше не перекрывается при растягивании.
- **Удобное масштабирование и изменение размера**: окно растягивается за края и уголок `◢` (доступен и при скрытом статусе в прозрачном режиме), масштабируется вращением колёсика мыши с зажатым `Ctrl` (`Ctrl + Колёсико`), клавишами `+` и `-`, жестом `Shift + зажатие ЛКМ` или через готовые пресеты («Размер окна») в контекстном меню.
- **Раскладка клавиатуры**: клавиши управления (`R`, `T`, `Ctrl + Q`, `Пробел`, `Esc`) теперь работают на русской и любой другой активной раскладке.
- **Отдельный звук окончания круга**: добавлена независимая настройка звука для промежуточных раундов (пресеты или свой `.wav` файл) в контекстном меню.
- **Обновлённая крупная иконка и панель задач**: обрезаны лишние поля иконки, окно отображается на панели задач Windows, унифицирован `AppUserModelID`.
- **Исправления стабильности**:
  - Устранено залипание цвета цифр после завершения круга и самопроизвольный перезапуск мигания после сброса.
  - Исключено дублирование цикла обновления таймера.
  - Двойной клик по окну больше не запускает/не останавливает таймер перед вводом времени.
  - Колёсико мыши плавно меняет время шагом по 10 секунд для интервалов меньше минуты и сохраняет статус кругового режима.
- **Поддержка Linux**: кроссплатформенный синтезатор WAV-звуков через системные аудиоплееры (`paplay`, `pw-play`, `aplay`, `ffplay`), совместимость курсоров и прозрачности, скрипт сборки `scripts/build_linux.sh` и GitHub Actions workflow.

---

### Установка:
- **Windows**: скачайте `Just Timer.exe` и запустите его (установка Python не требуется).
- **Linux**: скачайте бинарный файл `Just-Timer-Linux` (если прикреплён к релизу) и сделайте его исполняемым (`chmod +x Just-Timer-Linux && ./Just-Timer-Linux`), либо соберите командой `./scripts/build_linux.sh` (потребуется `python3-tk`).
